# Kaupankäyntilähteiden tiedostovertailu

Tämä inventaario kattaa listatut alkuperäiset kaupankäynti-, suodatus-, strategia-, OHLCV- ja Solana-swap-hakemistot. Selaimen vastine kertoo lähimmän toteutuspolun. Testipariteetti edellyttää erillisiä vertailukokeita. Katso [vastuualueiden erot](PORTING.md).
